# Changelog

## 0.3.0 - 2026-09-29

- Add `@gbesse/jev-runtime` for canonical wire serialization, preflight checks, conservative request budgeting, and bounded retries.
- Add `@gbesse/jev-conformance` for cross-provider protocol, accuracy, calibration, repeatability, latency, and cost reports.
- Add `@gbesse/jev-context` for ranked context shaping, reserve-aware budgets, redaction, and stable fingerprints.
- Add `@gbesse/jev-receipts` for canonical SHA-256 digests and tamper-evident Ed25519 receipts.
- Add `@gbesse/jev-vision` for provider-neutral visual decision contracts and an OpenAI-compatible image adapter.

## 0.2.0 — 2026-09-25

- Added `@gbesse/jev-router` 0.1.0 with bounded hierarchical routing, provider failover, confidence gates, loop detection, strict response validation, and an explicit authorization boundary.
- Added ContractLab stability runs, seeded option permutations, fixed-order and permutation flip rates, consensus metrics, probability drift, and rounding-aware argmax checks.
- Added Pulse threshold simulation and recommendations across coverage, accuracy, Wilson confidence bounds, quantization, review cost, and false-accept cost.

## 0.1.0 — 2026-09-24

- Initial public release of ContractLab, Shadow, Pulse, TriageOps, and Set.
